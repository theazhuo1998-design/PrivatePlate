# Data license

Unless otherwise noted, the files under `fixtures/` are dedicated to the public
domain under **CC0 1.0 Universal**.

The full CC0 legal code is included at `fixtures/LICENSES/CC0-1.0.txt`.
The canonical Creative Commons reference is:
`https://creativecommons.org/publicdomain/zero/1.0/`.

These fixtures are AI-assisted synthetic demonstration data created specifically
for the PrivatePlate prototype. Their provenance is documented in
`fixtures/PROVENANCE.md` and `fixtures/MANIFEST.json`; they are not redistributed
clinical datasets, measured nutrition databases, medical advice, real household
records, or third-party food datasets.

Nutrition and quantity values in the fixtures are engineering estimates for
demonstration only. CC0 permits reuse and redistribution, but it does not make
these values authoritative nutrition or medical data.

This data dedication applies only to the files under `fixtures/`. PrivatePlate
source code is licensed separately under Apache-2.0. Model weights, production
food databases, real household data, and advanced chronic-disease data assets
are not part of this repository and are not covered by this data dedication.
